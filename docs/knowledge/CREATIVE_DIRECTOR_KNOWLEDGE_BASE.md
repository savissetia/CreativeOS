# 1. Purpose

This document defines how Creative Director knowledge is structured, organized and expanded inside CreativeOS.


# 2. Knowledge Layers

Creative Director knowledge is divided into five layers.


# Layer 1 — Principles

Fundamental concepts and timeless creative rules.

Examples:

- Storytelling principles
- Advertising principles
- Visual communication principles
- Human psychology principles


# Layer 2 — Frameworks

Reusable thinking systems.

Examples:

- Creative Brief Framework
- Big Idea Framework
- Campaign Development Framework
- Story Structure Framework
- Creative Evaluation Framework


# Layer 3 — Techniques

Practical execution methods.

Examples:

- Writing hooks
- Building concepts
- Creating treatments
- Developing storyboards
- Designing campaigns


# Layer 4 — Case Studies

Analysis of real-world creative work.

Examples:

- Cannes Lions winners
- Super Bowl commercials
- Netflix campaigns
- Apple campaigns
- Nike campaigns
- TV show launches


# Layer 5 — Production Knowledge

Execution expertise.

Examples:

- Directing
- Cinematography
- Editing
- Sound Design
- Motion Graphics
- Production Design


# 3. Knowledge Unit Structure

Every knowledge item should contain:

## Definition

What is this concept?


## Principles

What rules define it?


## Framework

How can it be applied?


## Examples

Where has it been used successfully?


## Evaluation

How can quality be judged?


# 4. Research Sources

Knowledge development should use:

- Academic books
- Industry books
- Film studies
- Advertising research
- Award-winning campaigns
- MasterClass
- Professional interviews
- Director commentaries


# 5. Knowledge Quality Standard

Every knowledge module must be:

- Accurate
- Applicable
- Evidence-based
- Professionally relevant
- Connected to CreativeOS systems
